ESP32 FM Modulation
================================================================================

Background
--------------------------------------------------------------------------------
[ESP32FMRadio](https://github.com/Alexxdal/ESP32FMRadio) demonstrates how to
generate a modulated GPIO signal.

* [I2S (Inter-IC Sound)][I2S]
    * I2S (Inter-IC Sound) is a synchronous serial communication protocol usually used for transmitting audio data between two digital audio devices.
