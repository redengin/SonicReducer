Background
================================================================================
People are interested in open-source/hardware creation of parametric speakers.
* [Turning Sound Into a Laser](https://www.youtube.com/watch?v=aBdVfUnS-pM)

Sonic Reducer
================================================================================
This project provides
* parametric speaker design
    * amplifier guidance
* embedded rust to generate the signal (a 40 KHz carrier wave)
* Bluetooth support
    * Use device as Bluetooth speaker - send audio to be translated to 40 KHz carrier wave
