Background
================================================================================
People are interested in open-source/hardware creation of parametric speakers.
* [Turning Sound Into a Laser](https://www.youtube.com/watch?v=aBdVfUnS-pM)

Sonic Reducer
================================================================================
This project provides
* parametric speaker design
    * amplifier guidance
* embedded hardware to create the signal
    * Bluetooth support
        * Use device as Bluetooth speaker
        * Configure device properties
